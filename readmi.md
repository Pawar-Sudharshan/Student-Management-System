# 🎓 Student Management System

A fully responsive **Student Management Portal** built using **HTML, CSS, and Bootstrap 5**. This project provides an intuitive interface for managing student information, registrations, attendance, profiles, and communication through a modern and mobile-friendly design.

## 🚀 Features

### 🏠 Home Page

* Responsive Bootstrap Navbar
* College Logo
* Navigation Links:

  * Home
  * About
  * Courses
  * Contact
* Login Button
* Hero Section with Welcome Message
* College Description
* Register Now Button
* Feature Cards:

  * Student Registration
  * Attendance Management
  * Results Management
* Footer with Copyright Information
* Social Media Links

### 📝 Student Registration Form

* Full Name
* Roll Number
* Email Address
* Mobile Number
* Gender Selection
* Branch Selection
* Date of Birth
* Address
* Upload Photo
* Terms & Conditions Checkbox

#### Validation

* Required Fields
* Email Format Validation
* Mobile Number Length Validation

### 📊 Student Dashboard

* Total Students Statistics
* Present Students Count
* Absent Students Count
* Placements Count
* Search Functionality
* Responsive Student Table

### 👤 Student Profile

* Profile Image
* Student Information
* Roll Number
* Branch
* Email
* Mobile Number

### 📞 Contact Us

* Name
* Email
* Subject
* Message Form
* Success/Error Alerts

1. Clone the repository:


```bash

```

3. Open `index.html` in your browser.
