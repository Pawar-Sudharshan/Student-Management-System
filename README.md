# Student Management System

A responsive **Student Management Portal** built with **HTML, CSS, and Bootstrap 5**.

This project includes pages for student registration, dashboard monitoring, student profiles, and contact communication.

## Pages Included

- `index.html` — Home page
- `home.html` — Secondary landing page
- `login.html` — Login page
- `register.html` — Student registration page
- `dashboard.html` — Student dashboard with statistics cards and table
- `profile.html` — Student profile page
- `contact.html` — Contact form and support information
- `addStudent.html` — Add student form
- `editStudent.html` — Edit student page
- `viewStudents.html` — Student listing page
- `logout.html` — Logout page

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## Bootstrap Components Used

- Navbar
- Grid system
- Typography
- Buttons
- Cards
- Forms
- Tables
- Alerts
- Badges
- Dropdowns
- Collapse
- Accordion
- Modal
- Carousel

## Features

- Responsive layout for mobile, tablet, and desktop
- Collapsible navbar on small screens
- Form fields for contact, registration, and student details
- Dashboard statistics cards with data summaries
- Responsive tables and badges for attendance status
- Profile card with student information
- Contact form with dropdowns, alert message, modal, and carousel

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Pawar-Sudharshan/Student-Management-System.git
```

2. Open the project folder:

```bash
cd Student-Management-System
```

3. Open `index.html` in your browser.

> For the best experience, use a local web server such as VS Code Live Server.

## Notes

- The project uses the `asserts/` folder for images and icons.
- If using the pages in a browser, make sure the folder structure remains unchanged so links and images resolve correctly.
- The contact page includes form UI only; it does not submit data to a backend server.
